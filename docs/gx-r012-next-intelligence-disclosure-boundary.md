## 2. The Progressive Disclosure Model

The guest is never presented with the entire infrastructure graph at once. Information unfolds in discrete, earned layers:

```
                    CURRENT UNDERSTANDING
                            │
                            ▼
                    WHAT MATTERS NOW
                            │
                            ▼
                      ARCHITECTURE
                            │
                            ▼
                        EVIDENCE
                            │
                            ▼
                      INVESTIGATION
                            │
                            ▼
                    NEXT INTELLIGENCE
```

Each layer is revealed only after the preceding layer has established its cognitive anchor.

---

## 3. Canonical 7-Level Disclosure Ladder

| Level | Name | Cognitive Purpose | Key Guest Surfaces |
| :---: | :--- | :--- | :--- |
| **0** | **Orientation** | *"Where am I?"* | Domain Context Anchor (`UNDERSTANDING · example.com`), Status Indicator, Snapshot Timestamp |
| **1** | **Meaning** | *"What has Nebula understood?"* | Synthesized Executive Brief narrative, High-level Perimeter Profile |
| **2** | **Attention** | *"What deserves attention?"* | Evidence-backed Findings, Significance explanations, Actionable callouts |
| **3** | **Architecture** | *"How does the infrastructure relate?"* | 8-Category Infrastructure Matrix, Ingress Path Topology, Detected Technologies |
| **4** | **Evidence** | *"What supports this understanding?"* | Protocol signals, Telemetry summary, Cryptographic verification hashes |
| **5** | **Investigation** | *"Why does this observation exist?"* | Contextual Investigation Drawer, Wire Signals, Raw Collector Records |
| **6** | **Next Intelligence** | *"What else can Nebula meaningfully explain?"* | Contextually derived doorway to the next structural understanding |

> **Critical Distinction:** Level 6 is **not** "show everything" or an uncurated telemetry dump. It is a controlled, contextually derived doorway into a specific adjacent intelligence surface.

## 4. Contextual Next Intelligence Selection

Generic CTAs like `"Explore more"` or `"See full report"` are strictly prohibited. The next disclosure must be derived directly from the investigated component:

```
WHAT DESERVES ATTENTION
One thing deserves attention.
Your public edge infrastructure has an unusual routing relationship.
[ Understand why → ]
         │
         ▼
UNDERSTANDING THE EDGE
The traffic path suggests a multi-layer ingress architecture.
         │
         ▼
NEXT UNDERSTANDING
How the public edge connects to the underlying infrastructure.
[ Explore architecture → ]
```

The CTA explicitly describes the cognitive domain the guest is about to understand.

## 5. Persistent Context Preservation

Progressive disclosure must never destroy spatial orientation.

* **Domain Anchor:** The investigated domain remains persistently anchored at the top of the canvas:
  ```
  UNDERSTANDING · example.com
  ```
* **Continuous Cognitive Lineage:** The guest can always trace:
  $$\text{What domain?} \longrightarrow \text{What am I looking at?} \longrightarrow \text{Why am I seeing it?} \longrightarrow \text{What can I understand next?}$$
* **No Sudden Transitions:** No unexpected full-page routing, unannounced report views, or redirects into generic dashboards.

## 7. Disclosure Trigger Rules

A next disclosure layer may appear **only** when all three conditions are satisfied:

1. **Layer Completeness:** The current layer has established clear meaning.
2. **Backend Evidence Grounding:** Concrete backend wire signals exist to substantiate the next layer.
3. **Genuine Cognitive Addition:** The next layer adds new architectural insight ($\text{More data} \neq \text{More intelligence}$). Repetitive information is never disclosed as depth.

$$\text{Eligible For Disclosure} = \text{MeaningComplete} \land \text{EvidenceExists} \land \text{NewInsight}$$

## 8. No Artificial Gating or Paywalls

The disclosure boundary operates on pure backend truth:

* ❌ **Prohibited:** `"Wait 3 seconds to unlock next layer"`
* ❌ **Prohibited:** `"Complete analysis to continue"`
* ❌ **Prohibited:** `"Upgrade to see more"`
* ❌ **Prohibited:** `"Sign up to reveal detailed results"`
* ❌ **Prohibited:** `"Unlock advanced findings"`
* ❌ **Prohibited:** Artificial spinner delays before disclosure

> **If intelligence is already computed by the backend, it is disclosed immediately upon guest intent.**

## 9. Investigation Boundary & Raw Telemetry Containment

The progressive ladder terminates at a strict technical boundary:

```
MEANING
   ↓
CONTEXT
   ↓
OBSERVATION
   ↓
EVIDENCE
   ↓
RAW EVIDENCE (Deepest Guest Surface: Sanitized Collector Payloads)
   ↓
═══════════════════════════════════════════════════════ [HARD BOUNDARY]
   ✕
INTERNAL SYSTEM (Secrets, Auth Tokens, Tenant IDs, Infrastructure Internals)
```

Raw collector wire payloads (DNS records, TLS handshake traces, HTTP headers) are the deepest guest-visible layer. Internal system state and multitenant metadata must never enter the guest canvas.

### Core Security Invariant:
> **"Progressive disclosure is not progressive privilege."**

Going deeper into the guest intelligence hierarchy **never** grants:
* Authenticated Workspace access
* Private tenant resources or notes
* Private snapshot historical lineage
* Registered domain management capabilities
* Private findings or internal vulnerability rules
* Authenticated session privilege escalation

## 12. Disclosure Failure Resilience

If a deeper intelligence layer fails or returns partial data:

```
Current Understanding (Preserved)
        │
        ▼
Next Layer Query / Synthesis Fails
        │
        ▼
Preserve Current Cognitive State
        │
        ▼
Calm, Non-Alarmist Explanation ("Detailed edge routing topology is currently unavailable.")
        │
        ▼
Retry Option / Continue Inspection
```

* ❌ **Never** crash to a blank screen.
* ❌ **Never** dump unhandled error stack traces.
* ❌ **Never** redirect automatically to Workspace.
* ❌ **Never** lock the UI in an infinite full-screen spinner.
