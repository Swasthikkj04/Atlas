# FE-11: Accessibility & WCAG Standards

## 1. Objective
Defines accessibility standards, WCAG 2.1 AA compliance guidelines, keyboard navigation, focus management, and ARIA roles.

## 2. Accessibility Guidelines
* **Color Contrast:** Minimum contrast ratio of 4.5:1 for normal text and 3:1 for large text against dark backgrounds.
* **Keyboard Navigation:** Full keyboard navigation support using `Tab`, `Enter`, `Space`, and `Escape` keys.
* **Focus Indicators:** Visible, high-contrast focus rings (`outline: 2px solid var(--accent-primary)`) on focused interactive elements.
* **Semantic HTML:** Appropriate use of `<main>`, `<nav>`, `<header>`, `<footer>`, `<section>`, and `<article>`.
* **ARIA Attributes:** Explicit `aria-label`, `aria-expanded`, `aria-describedby`, and `role` attributes on custom UI widgets.
