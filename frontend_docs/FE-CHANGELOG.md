# Versioning Policy

Frontend releases follow Semantic Versioning.

- Major — Breaking architectural or product changes.
- Minor — New features and user experiences.
- Patch — Bug fixes, performance improvements, and documentation updates.

---

# Change Categories

Changes should be recorded under one or more of the following categories:

- Added
- Changed
- Deprecated
- Removed
- Fixed
- Security
- Performance
- Documentation
